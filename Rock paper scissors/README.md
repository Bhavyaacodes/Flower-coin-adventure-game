# ✂️ Rock Paper Scissors

A simple Rock Paper Scissors game built using Python.

## Features

- Random computer moves
- Score tracking
- First to 5 wins
- Input validation
- Round-by-round gameplay

## Concepts Used

- while loops
- if / elif / else
- lists
- random.choice()
- variables
- user input

## Run

```bash
py rock_paper_scissors.py
```
